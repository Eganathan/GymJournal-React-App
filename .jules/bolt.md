## 2024-04-02 - O(N) Array Find Lookups in React Loops
**Learning:** Found an O(N) performance bottleneck in `src/pages/WorkoutActive.js` during render. Nested `find` operations within an `.map` iteration caused performance issues during list rendering, particularly when typing search queries or appending bulk items where list size is N and categories/equipment size is M. Additionally, computations like `.reduce` done locally in component renders should be memoized to avoid expensive recalculations on timer intervals (e.g. 1-second elapsed timer in workouts).
**Action:** Replace `Array.prototype.find` inside render loops with O(1) lookups via `Map.get()`. Initialize the Map hooks defensively with `useMemo` at the top level to avoid memory churn. Extract local unmemoized `.reduce` aggregations (e.g., best 1RM estimation, and completions sets statistics) into `useMemo` hooks dependency-driven caching to survive frequent high-interval UI rerenders.
