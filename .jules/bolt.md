## 2024-05-24 - O(n) array lookup optimizations in React renders
**Learning:** Nested `Array.prototype.find()` operations within `Array.prototype.map()` in React render loops create severe O(n²) performance bottlenecks, especially during list rendering with search results or lists of items. The bottleneck is amplified when mapping over large arrays where each iteration searches another array to resolve relations (like resolving category and equipment names from IDs).
**Action:** Replace nested `.find()` array lookups with `useMemo`-wrapped `Map` generation using defensive optional chaining (`array?.forEach((item) => map.set(item.id, item))`), reducing the nested O(n²) iterations into O(n) preprocessing and O(1) loop lookups. Always ensure defensive checking since state variables may be uninitialized during the initial render.
